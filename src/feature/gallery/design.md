# Gallery Feature Design Guide

- Follow the root `DESIGN.md` as the governing visual contract when it exists.
- Keep the gallery on the warm Clay canvas so legacy static works and backend result cards feel like one collection.
- Result cards use a 24px visual rhythm: compact media preview, clear category badge, and readable title/description.
- Interactive controls must meet a 44px touch target.
- Use icon-led tabs for all result categories.
- Cover loading, empty, and error states explicitly.
- Do not nest cards inside cards.
- Do not use gradient text.
- Keep static gallery content and backend-managed uploads visually integrated on `/gallery`.
