# 偏振光学实验立体书 Plan

## 目标

为 PolarCraft 制作一个可直接预览的偏振光学实验页面，以光的本质和偏振表示为前导，再进入冰洲石双折射；复刻 [Every Joule · Lesson 1](https://iamtechartist.github.io/every-joule-lesson1/) 的立体书视觉与阅读形式。结果全部放在 `design-previews` 下。

## 设计方向

- 全屏 3D 桌面：浅木纹桌面、灰绿色布垫、金黄色布面精装书。
- 封面：中文书名「一束光的两种旅程」，副标题「冰洲石 · 双折射实验」，中央墨线晶体图。
- 内页：暖白纸张、宋体／衬线排版、书脊阴影、纸层厚度、朱红批注。左页解释，右页实验。
- 实验对象从书页上浮起：电磁波与偏振轨迹、透明菱面体、双像文字、两色光路、动态光轴与带刻度的检偏片。
- 底部半透明胶囊栏承担目录、翻页、暂停动画和合书操作；侧边提供各章实验参数、偏振读数和观察清单。
- 前两章可改变电磁波波长与振幅、偏振分量和相位；后四章可改变入射波长、入射偏振、晶体厚度，切换光路／光轴显示，并进行沿光轴无双折射的对照实验。
- 保留参考站的材质、构图和交互语法，重新编写冰洲石内容与实现，不使用对方品牌署名或课程文案。

## 七个跨页

| 跨页 | 学习目标 | 交互与验收 |
| --- | --- | --- |
| 01 光的本质 | 认识光是电磁波，理解 E、B 与传播方向的关系 | 调节 380–700 nm 波长与电场振幅，显示／隐藏 B；同步比较波形与频率，验证 c = λf |
| 02 偏振类型与表示 | 用两个正交分量理解线、圆与椭圆偏振 | 切换五种预设，调节 δ、Eₓ、Eᵧ；空间曲线与接收端投影同步，显示 ψ、χ 与旋向 |
| 03 布儒斯特角 | 理解反射光的偏振与布儒斯特角 | 调整入射角、切换水／玻璃／金刚石；一键到 θB，验证 p 分量消失、反射与折射垂直；拖动旋转视角 |
| 04 一个字，两个像 | 认识冰洲石双折射 | 打开书即可看到「光」的双像与立体晶体；完成旋转和消光观察任务 |
| 05 转动晶体 | 观察双像的相对位置 | 拖动晶体或调节转角；o 像固定，e 像绕行；改变厚度比较间距 |
| 06 让一个像消失 | 认识两束光的正交偏振 | 放入检偏片；0° 与 90° 明暗互换，自然光下 45° 两像等亮；切换线偏振入射 |
| 07 光的两种旅程 | 将现象与物理原理关联 | 切换波长观察色散；沿光轴让双像重合，再恢复普通方向 |

## 实现方案

1. **独立预览**：原生 HTML、CSS、JavaScript + 项目现有 Three.js 0.160.1 的本地副本，不新增项目依赖。
2. **场景**：正交相机、实体封面与页块、纸面 Canvas 纹理、绕书脊旋转的封面和翻页平面、局部透明晶体与墨线边框。
3. **材质与字体**：代码生成木纹和织物材质；本地 Noto Serif CJK 子集字体；随文件附带开源许可证。
4. **基础章节图示**：第一章以浮出书面的三维缎带、网格描边和场矢量表示 E、B 与传播轴，第二章以同一组 Ex / Ey 参数驱动空间偏振缎带、接收端轨迹和旋转矢量；偏振图示支持鼠标或触摸拖动旋转视角，重置恢复默认朝向。动画暂停、振幅与相位变化均实时同步。
5. **交互状态**：打开状态、七个章节、基础章节的波长／振幅／B 图层与偏振分量／相位、晶体角度与厚度、检偏片开关、检偏角、入射偏振、波长、光轴对照、图层开关、观察任务和动画暂停状态。所有控制器与画面同步。
6. **无障碍与移动端**：按钮名称、键盘翻页、原生滑杆、文字版、减少动态效果偏好；手机以右页实验为主，控制区可收起，并提供完整文字版。
7. **验收**：浏览器检查封面、七章节导航、基础章节参数与偏振分类、合书、目录、重置、角度及亮度、线偏振入射、厚度、色散、光轴重合、观察任务、图层开关和文字版；保存桌面与手机截图，检查控制区溢出与运行错误。

## 物理模型及边界

- 第一章采用真空中的理想单色平面波，E、B 同相且与传播方向垂直；屏幕振幅、空间尺度与播放速度仅作教学示意，不按真实光速绘制。
- 第二章采用 Ex = Ax cosτ、Ey = Ay cos(τ + δ)，以接收端视角表示偏振轨迹；线／圆／椭圆分类、ψ 与 χ 均由当前参数计算。左右旋明确采用本页观察方向与相位约定。
- 第三章采用空气到理想非吸收各向同性介质的斯涅耳定律与菲涅耳光强反射率；θB = atan(n₂/n₁)，介质折射率为可见光近似值。
- 采用平行晶面、近轴入射的教学模型：o 像固定，e 像随主平面方向绕行；不等于任意形状、任意入射方向下的完整光线追迹。
- 使用单轴晶体折射率椭球计算 e 光能量传播方向与离散角 δ，双像间距为 `Δx = t · tan δ`。厚度可在 4–12 mm 间调整，出射光与入射光平行。
- 自然光下，两束光的初始强度各占总入射光强的 1/2；线偏振入射时分别为 `cos²φ` 与 `sin²φ`，φ 相对 o 光偏振方向。
- 检偏角 θ 相对 o 光偏振方向定义：`Iₒ = Iₒ,入 cos²θ`，`Iₑ = Iₑ,入 sin²θ`。忽略吸收和界面反射。
- 自然光入射且 θ = 45° 时，两像各为总入射光强的 25%，不是各为 50%。检偏片改变明暗，不改变双像位置。
- 提供 400、550、589 nm 三组近似主折射率；e 光有效折射率依赖传播方向。沿光轴传播时 δ = 0、双像重合。
- 光路动画展示纸面到晶体、晶体内分离和出射后的路径；当前并未调用项目完整的 `computeRefraction` 求解器。
